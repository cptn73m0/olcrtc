# Форк olcrtc

Этот репозиторий - форк [openlibrecommunity/olcrtc](https://github.com/openlibrecommunity/olcrtc).
Апстрим заархивирован 30 сентября 2026, обновлений оттуда не будет.

## Зачем форк

Эксплуатация на реальном сервере выявила дефект: при плановой ротации сессии
туннель простаивает 55-56 секунд вместо 2-3. В это время клиент показывает
"подключено", потому что WebRTC-сессия с SFU жива, а smux-сессия уже мертва.
Подробный разбор - [docs/fork/session-reinstall.md](docs/fork/session-reinstall.md).

Апстрим починить это не может: он закрыт. Поэтому форк берет на себя роль
мейнтейнера транспортного слоя.

## Границы работ

- Чиним надежность сессии: reinstall, handshake, liveness, переподключение.
- Не добавляем новых провайдеров и транспортов.
- `wbstream` считается мертвым (сервис закрыл авторизацию для не-сотрудников),
  код провайдера не развиваем.
- Публичный wire-формат меняем только с версионированием и одновременным
  обновлением обеих сторон.

## Совместимость клиентов

Форк ядра несовместим со старыми клиентами, если меняется wire-формат.
Клиент `olcbox` (Kotlin Multiplatform) форкается и пересобирается под ту же
версию протокола. Пока формат не менялся, текущая сборка совместима со старыми
клиентами.

## Сборка и проверка

```sh
mage check     # линт и тесты
mage build     # бинарь в bin/
go test -race ./...
go build ./cmd/olcrtc
```

Локальная сборка без mage:

```sh
go build -o bin/olcrtc ./cmd/olcrtc
```

## Правила разработки

1. `ub-mode`: сначала сделать, чтобы работало, потом сделать правильно, потом
   практика. Мелкие проверяемые шаги, тест до кода, лог действий.
2. `AGENTS.md` апстрима остается в силе: код и коммиты на английском, документация
   на русском, `mage lint` без замечаний, conventional commits.
3. Ветки: `master` - рабочая линия, изменения идут через короткие ветки.
4. Каждый коммит отвечает на три вопроса: зачем, что изменилось, как проверено.
